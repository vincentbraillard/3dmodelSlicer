Maquette en tranches

STL / 3MF → pièces SVG pour découpe laser (tranches + ergots + plateau à fentes). Unités : mm.

0. Créer un tore (optionnel)

Génère un modèle : une forme balayée le long d'un tore, inscrite entre les diamètres donnés.

L'enfoncement coupe le bas de la forme : on obtient un méplat plat pour les ergots au lieu d'une pointe.

1. Modèle

Le modèle doit être posé « à plat » : le bas (Z min) touche le plateau.

2. Coupe

Mode rayonnant : les pièces sont des demi-plans autour de l'axe vertical Z (tore, vase…). Le centre (0, 0) est le milieu du modèle ; les champs X/Y ne servent qu'en mode rayonnant.

4. Export

Dessine une forme fermée

Un seul trait continu : la forme se ferme toute seule. Le cercle pointillé représente la section du tore ; le point le plus éloigné du centre est ajusté dessus. Le dessin est recentré, et le twist ne peut valoir que 0°, 360° ou 720°.
